## Notas de Implementación

### Recordatorios WhatsApp
Ya tenemos la integración con Evolution API. Solo falta:
1. Crear un cron job que consulte citas próximas (24h y 1h antes)
2. Formatear el mensaje con los datos de la cita
3. Enviar por WhatsApp usando la instancia del usuario

### Pagos al Reservar
Ya tenemos Stripe integrado. Solo falta:
1. Añadir campo de "precio" al tipo de evento
2. Crear sesión de Stripe Checkout antes de confirmar la reserva
3. Verificar pago antes de crear la cita

### Página Pública
Ya tenemos la estructura `/[username]/[slug]`. Falta:
1. Crear página de perfil con foto, bio, servicios
2. Mostrar disponibilidad en tiempo real
3. Permitir reserva directa desde el perfil
